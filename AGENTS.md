# AGENTS.md

Agent guidelines and rules for working in this repository.

## Coding Rules

- Every file must end with a blank line (a single trailing newline).
- After every fix, the changed code must be reviewed (e.g., re-read the diff for correctness, regressions, and adherence to these rules).
- If something is unclear or ambiguous, ask a clarifying question instead of deciding on your own.
- Keep changes consistent with the existing structure, naming, and style.
- Preserve existing conventions unless a rule here overrides them.
